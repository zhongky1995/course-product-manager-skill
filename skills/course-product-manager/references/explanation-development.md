# 内容理解与教学展开

用于解释型课程、阅读型知识产品、完整教学单元，以及反复被指出空泛、跳步、浅薄的课程重构。普通局部润色不必执行完整流程。这里的方法服务实际正文，不要求新增一套表格、控制文件或让用户逐步审批。

## 1. 先判断作者有没有足够内容可教

承接已有受众、目标、观点和材料，先确定本节要建立的理解或能力，再优先读取用户已提供、当前可访问且与该问题相关的资料。不要先凭主题写完通用讲解，再用案例标题装饰。资料不足时只为具体缺口查证；能讲清的部分继续推进，无法自行取得且影响交付的关键信息才询问。

在安排章节之前，针对当前问题形成一份简短的内容说明；可以使用工作笔记，无须另交文档。它应让作者能够解释：

- 当前究竟主张什么，与读者原有认识有什么差别？
- 哪些材料使这个判断成立，通过什么过程，而非只与它有关？
- 有什么合理的不同解释或选择，什么条件会使判断改变？
- 还不知道的是什么，它阻止哪一项结论，是否仍能讲清已知部分？

这不是四栏模板。已经在材料或前文建立的内容可直接沿用。核心是检查作者能否不用大词与目录，把问题说清楚。若只能讲“很重要、要结合业务、持续迭代”，暂时还没有足够解释；应定向读材料、比较具体做法或缩小尚无依据的断言。不要因材料不足编造过程，也不要把所有讨论缩成风险提醒。

阅读来源时看具体任务、原有做法、发生的改变、观察到了什么、怎样得出判断。把它与自己的主张相接；只摘结论和边界，会丢掉最能教学的部分。原始材料数量、知名企业名字和研究标签均不代替这项工作。

成稿时把选中的事实、机制和案例写成读者实际能看到的内容：交代起点，展开影响判断的变化与依据，写出结果，并说明它怎样支持当前概念。只出现“案例：某公司转型”或“讲解上述机制”仍是备课计划。按本节用途选择展开程度，不要求每段套同一顺序；回读时检查下一步所需的信息是否已经交给读者。

首次引入承载判断的专业概念时，核对该领域的定义、对象和适用口径，再用材料解释。算例计算正确不等于概念使用正确；检查术语指向的是哪一项事实或数量，而不是让读者凭“这个”“那部分”猜测。对定义不确定时查可靠来源；若该术语并非教学必需，可以用准确的普通语言说明关系，不为了专业感添加未经核实的名称。

### 新命题怎样展开

尚无完整长期案例的领域，可以从已有事实与可观察能力出发做条件推理。明确区分：已具备的条件、为讨论而设定的条件、在这些条件下的推论、还需要实际检验的结果。

例如，系统能保存讨论记录，只能支持“记录可以取得”。要讨论组织能否积累经验，还需解释记录是否保留了理由、后续是否找得到、原条件是否仍适用，以及错误认识怎样修订。可用教学情境展开这些关系，但不能再以情境中成功的结果证明“该系统能提高组织能力”。

## 2. 选择本单元真正要建立的认识

主要问题可以包含必要子问题，不强行“一章只有一个知识点”。检查每部分是否在回答当前问题，还是为了覆盖全课关键词被装进来。

把读者起点与终点写具体。例如，“原先按完成件数评价工作，学后能解释任务复杂度改变时为什么这个比较失真”，比“理解效率、质量、组织与增长”更能指导写作。认知变化不必转成操作清单；也可以由解释陌生情形、比较两个主张来表现。

为关键转折确定依赖关系：读者需要先看见什么事实，才能接受这里的区别；这个区别又产生了哪个尚未回答的问题。不要用“接下来讲X”代替为什么需要X。

一种可用的推进是“材料产生疑问—比较形成判断—解释机制—回到细节—改变条件”，但不是固定章法。有时定义先行、先给结论或完整故事更自然。以读者此刻需要什么为准。

## 3. 让案例承担清楚的作用

| 用途 | 应带来的认识 | 不足以承担什么 |
| --- | --- | --- |
| 引出问题或作类比 | 看见原有解释的不足，产生值得研究的问题 | 证明技术能力或真实经营效果 |
| 建立概念或区别 | 看见相似行为为何有不同目标、依据与后果 | 仅靠角色名称判断谁更专业 |
| 演示机制或方法 | 同一材料怎样经过具体处理，哪些依据改变了结果 | 只展示输入与漂亮终稿，把中间工作藏起来 |
| 比较方案 | 理解两种合理安排在不同条件下的取舍 | 预设一个愚蠢对手让结论稳赢 |
| 提供经验依据 | 说明真实观察支持的主张及其范围 | 从一次观察推出普遍因果 |
| 检验迁移 | 原条件变化后，仍能使用已经建立的关系 | 仅更换人物、行业或名词复述原答案 |

案例可有多个用途，但作用变化时要让读者知道为什么继续看它。无需把分类写进正文。短引例无需同时具备完整输入、过程、反馈和练习；核心过程演示则不能用短引例替代。

### 对比要解释行动背后的理解

“店员推荐销量最高的商品，另一位店员先问用途”只并排陈列了动作。若要讲判断差异，还要知道顾客在完成什么任务、两人各把需求理解成什么，以及用途如何改变推荐标准。

例如给长期搬家的人选收纳箱，“销量高”能提供一个候选，却不能回答尺寸能否进入车厢、能否反复搬运。补上这些条件，读者才看见销量与适用性的关系。这里并不证明“先问用途的人总是正确”；销量仍可能提供有用信息。材料应容纳合理的替代判断。

这不是固定用该例子开课。它示范的是：解释差异来自哪些条件，而非给人物贴“新手/专家”的标签。

### 从人的能力谈技术能力时

人的专业工作可以提出一个有价值的问题，却不能单独证明技术能够完成它。分别展开：该工作包含什么判断；技术有什么有依据的能力；它取得哪些材料后可以参与哪一部分；输出怎样检查；尚不能判断的部分是什么。

教学示意可以对照同一任务在不同输入条件下的输出，再解释变化来自哪里。示意不是实测，加入更多背景也不保证一定更正确。能处理背景与能够形成可靠专业判断之间，仍可能缺评测、事实或现场条件。

## 4. 深度来自解释工作，不来自装饰

把篇幅用于能改变理解的地方：原来为何这样做，改变发生在哪个环节，合理替代为何不同，关键条件改变后结论如何变化。熟悉的常识压缩，新的机制充分展开。

可用下面的问题检查材料是否在工作，而不是强制每节逐题作答：

- 删除这个细节，会失去哪一项判断依据？如果没有影响，它可能只是背景。
- 删除这个概念，读者还能否解释刚才的差异？如果能，它可能尚未承担教学任务。
- 换一个条件，为什么结论会变或不变？如果只能回答“视情况而定”，关系尚未讲清。
- 这部分是否只是上段结论换词重述？回到同一案例时应增加关系、解释或新的用途。

图表用于解释对应、数量、状态、依赖或选择；与正文分工。图中的框与箭头不能替作者建立因果。数字只有在改变选择或揭示关系时才增加深度。把本来已知的预算算得很细，不能替代尚未解释的核心能力。

## 5. 用正文检查必要前提

挑出本单元最重要、最容易让读者跳步的判断或转场，在当前正文中找到它依赖的解释。对于完整单元，这应覆盖主要论证路径；不是只挑最好的一段作证。

检查时区分两种依据：

- **内容依据**：来源、事实或明确条件，支持主张本身。
- **教学依据**：正文已经如何把必要前提交给目标读者。来源正确不能代替这一步。

可以给审读者原始任务、读者起点、正文和必要原始材料，请其定位“第一次必须调用课外专业知识才能继续的地方”，引用原句，说明缺什么。不要提前提供作者的结论摘要、预设正确答案或自我评价。若确实需要提供前课，给实际前课材料，不能假定所有前提已经教过。

模型可以提出候选问题；作者仍要核对。模型能概括或答题，不等于文稿让它学会了。查看答案所用前提能否在正文中追溯；尤其留意审读者凭常识补出的机制。真实学员的疑问和作答另行记录。

局部算例复核完成，只结束该项问题。不能用它覆盖未处理的主旨、解释和语言问题，也不要每次修一个数字都重做无关全课检查。报告哪项缺口已修、哪些判断仍待验证。

## 6. 校准之后，检查能否独立写下一段

当用户反复指出“内容方向可以，但讲不清”时，先找具体差异，不立即推翻全部内容，也不默认只能改措辞。语言、材料顺序和单元范围都可能属于讲述问题。

已有用户认可片段时，分析它如何交代对象、推进理由、形成判断；保留适用语境。不要把用户某次用了“但是”、某段案例开头，转成全篇固定句式。没有认可样本时，用完整但范围有限的作品校准，不把作者自评登记为用户认可。

修订原段只能验证会接受修改。接着在已授权内容中完成一个未经逐句纠正的相邻单元或不同情境，再查同类问题。只复述规则、换名重写原例、重复既有算例，都不能验证迁移。

若仍失败，按观察改变工作方式：

- 说不清机制或替代解释：回到材料研究与领域判断，或明确缩小尚不能支持的主张。
- 判断成立但讲述断裂：调整单元范围和认识顺序，补实际缺失的解释。
- 推理连贯但语言生硬：做语句与整篇回读，使用[表达审查](expression-review.md)。
- 审读不断通过而用户仍困惑：检查审读是否靠自身知识补全，改用实际疑问与正文依据校准；必要时建议有相应知识的编辑或真实试学。

这些结果不能预先归因为某个模型差，也不能靠增加审读次数保证解决。更换工具、模型或编辑方式后仍需看实际作品。没有获授权的外部协作不自动执行；已有授权工作继续推进，不为了流程把任务停给用户。
